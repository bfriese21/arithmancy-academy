# Arithmancy Academy

A wizarding-themed arithmetic game: duel magical creatures with addition,
subtraction and multiplication.

**Play: https://bfriese21.github.io/arithmancy-academy/**

- 20 creatures on a 3-to-34 HP ladder, ending with The Dark Wizard
- 22 wizard ranks, First Year through Legend of Arithmancy
- 124 collectible cards across six sets, in five rarity tiers
- Escalating spell combos, Chocolate Frog packs, House Cup, daily streak

Single self-contained HTML file. Progress saves in the browser; the setup
screen has a transfer code for moving between devices.
